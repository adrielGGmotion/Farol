# Security Policy

## Reporting a vulnerability

If you find a security vulnerability in Farol, please **do not open a public
issue**. Instead, report it privately using GitHub's
[Private vulnerability reporting](../../security/advisories/new)
feature.

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce it, if possible.
- Affected versions.

You should receive an acknowledgement within a few days. We do not offer a
security bounty, but we will credit you in the advisory if you wish.

## Supported versions

Security fixes are only provided for the latest release. Older versions are
not supported.
